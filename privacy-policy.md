# Privacy Policy

### 1. Stored Data

All Toolkit for YNAB settings and toggle state data is stored on your computer in Safari. We do not sync any data to the cloud.

### 2. Diagnostics

This Safari-focused fork does not send crash reports or analytics to a third-party telemetry provider. When errors occur, diagnostic details stay local in Safari developer tools unless you decide to include them in a support request.

### 3. Permissions

Toolkit for YNAB only runs on `https://app.ynab.com`, the web app host needed for YNAB access. We do not collect passwords, bank account details, or budgeting data. The codebase remains auditable, so you can inspect exactly what the extension does before shipping or using it.

The storage permission is asked for simply so that we can store both user settings and maintain state of toggles such as "Toggle Privacy" across reloads of the website.
