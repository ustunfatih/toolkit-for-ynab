# Privacy Policy

### 1. Stored Data

All OpenBudget for YNAB settings and toggle state data is stored on your computer in your browser. We do not sync any data to the cloud.

### 2. Diagnostics

This Safari-focused fork does not send crash reports or analytics to a third-party telemetry provider by default. When errors occur, diagnostic details stay local in the browser or Safari developer tools unless you decide to include them in a support request.

### 3. Permissions

OpenBudget for YNAB only runs on `https://app.ynab.com` and `https://app.youneedabudget.com`, which are the web app hosts needed for YNAB access. We do not collect password, bank account, or budgeting data. The codebase remains auditable, so you can inspect exactly what the extension does before shipping or using it.

The storage permission is asked for simply so that we can store both user settings and maintain state of toggles such as "Toggle Privacy" across reloads of the website.
